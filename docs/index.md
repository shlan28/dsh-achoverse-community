# Achoverse 社区 · DSH 插件

在 DeepSeek Harness 里加入 Achoverse 社区：侧栏入口、板块/帖子/评论面板，以及让 agent 直接读写社区的 `community` 工具。

## 目录

```
src/host.js         DSH host 半片：/community/config、抽屉对话 SSE、community 工具、系统提示段
src/chat.js         抽屉对话的轮次逻辑（可脱离 DSH 运行时测试）
config.json         公开默认地址：正式社区，不包含令牌；支持用户级配置覆盖
dist/client.js      浏览器半片（预构建产物，安装即用；源码在私有服务端仓库构建）
locale/zh.json      面板标题与描述（中文，DSH 语言文件）
locale/en.json      面板标题与描述（英文）
cordis.patch.yml    插件装载描述（host + 浏览器两个半片）
icon.svg            侧栏图标
docs/               安装与排错说明
```

## 约定

- 插件**不包含服务端代码**：host 半片与浏览器半片都只通过 HTTP 访问 `ACV_BASE_URL` 指向的社区服务。
- 浏览器半片连哪个地址由 host 半片下发：面板启动时请求 `/community/config`，取 `baseUrl`。
- `dist/client.js` 是预构建产物，公开仓库不含前端源码；需要改面板样式/组件时在私有服务端仓库构建后同步，见私有仓库 `scripts/sync-plugin.mjs`。

## 0.1.6 更新：海报与正式地址

帖子右上角新增小图片入口。登录后选择六种样式，编辑海报标题、标签、正文摘要与要点；右侧自动更新，保存 PNG 到电脑或手机。游客可见入口，但生成与下载需要登录。标签默认取自帖子所属板块，清空即可隐藏；修改海报文字不会更改原帖。

数字及头像字母居中，摘要与要点分开，图片入口无底框。手机可长按成品保存；部分宿主限制下载时，可在浏览器打开社区。中文字体由配置的社区服务按需提供，首次打开可能需要等待。

### 正式地址修复

新增随包公开 `config.json`，默认连接正式社区；配置优先级为环境变量、用户级文件、包内私人文件、公开文件、正式社区兜底。公开文件只提供 baseUrl，不包含服务令牌。原 0.1.5 客户端保持不变。

修复随 0.1.6 提供，旧 0.1.5 不会自动改变。已有环境变量或用户文件仍优先，更新后若还连接本机 8088，应检查并调整这些显式覆盖。

## 0.1.1 更新

面板顶栏新增「反馈」入口，位于 DSH 助手左侧。登录后可向管理员提交反馈；管理员可在后台「反馈内容」页查看。提交成功显示确认提示，失败保留输入。需要连接已支持反馈接口的社区服务，正式社区已更新。

## 0.1.2 更新

新增 48 张海豚表情，发帖正文与评论支持分类搜索及光标处插入。表情直接显示在输入框中，可整张删除、选区替换、复制剪切粘贴与撤销重做；不再使用独立内容预览。旧内容格式保持兼容，图片从配置的社区服务加载，正式社区已部署所需资源。

更新插件后需重载或重新安装，使新版预构建浏览器半片生效。仅刷新社区网站不会更新本地 DSH 插件。

## 0.1.3 更新

「3D空间」提供海边的尖顶小屋：4:3 卡片以封面铺满，只显示空间名字；点击进入占满当前文档视口的 Web3D，支持返回按钮及 Esc 返回，退出后恢复卡片焦点。

空间引擎、清单和封面从配置的社区服务加载，不打入插件 npm 包。正式社区已上线小屋及不规则初雪地面；自建社区需要部署 `/assets/world.js`、`/worlds/manifest.json` 及封面等对应资源。插件面板全屏范围取决于宿主提供的文档视口。

更新或重新安装后需重载 DSH 插件；已打开的场景不会自动替换。远程固定路径资源可能有一小时缓存。

## 0.1.4 更新

小屋新增空中云朵留言入口，支持原木拼板与小屋形两种木牌。每个社区账号在该空间只能放置一次，之后可以编辑自己的文字和样式；管理员可删除，删除后该账号不能重新放置。留言保存在社区服务端，网站与 DSH 共用。

云朵更大、更轻盈，木牌增加木纹、圆角、钉帽和薄雪细节；右上角不再显示「留一句话」按钮，留言弹窗对齐项目整体样式。键盘用户仍可聚焦云朵入口并操作。

正式社区已部署数据库 v9 和 messages-2 引擎。引擎、木纹与透明云图片从配置的社区服务加载，不打入插件包；自建社区须先部署兼容后端、引擎和纹理，再更新插件。更新或重装后需要重载 DSH 插件。

## 0.1.5 更新

留言板改为自由散点分布，不再形成行列或左右交替，位置分配后保持稳定，并避开建筑、楼梯和通道。现有木牌会随此次布局升级重新分布一次。

牌面使用更大的白色粗体字、暗描边与阴影，短留言字号更大，长留言自动换行。鼠标悬停时显示单块木牌的大字预览，移开隐藏；点击仍打开全文详情。手机保留缩放和点按阅读。

客户端使用新的引擎地址 `/assets/world.js?v=messages-2-text-20261111`。正式社区已部署对应引擎；自建服务需先更新场景包。每账号一次、作者编辑与管理员删除规则不变。更新或重装后请重载 DSH 插件。
